# Μηχανολογία ΕΠΑΛ: σημειώσεις και ασκήσεις

Στατική εφαρμογή (vanilla HTML, CSS και JavaScript, χωρίς build step) με θεωρία, ασκήσεις Τράπεζας Θεμάτων και διαδραστικές προσομοιώσεις για τα μαθήματα του Τομέα Μηχανολογίας των ΕΠΑ.Λ.

Η εφαρμογή ανοίγει απευθείας από το `index.html` και μπορεί να δημοσιευτεί ως έχει σε GitHub Pages. Το περιεχόμενο ασκήσεων παράγεται από το [epal-mech-agent](../README.md), που βρίσκεται στο γονικό repository.

## Δομή έργου

| Διαδρομή | Περιγραφή |
|---|---|
| `index.html` | Κέλυφος της εφαρμογής. Όλα τα `<script>` tags φορτώνονται εδώ. |
| `css/style.css` | Όλο το CSS, μαζί με τα χρώματα του dark mode και τις μεταβλητές μεγέθους γραμματοσειράς. |
| `js/app.js` | Όλη η λογική: routing, rendering, διαδραστικότητα, dark mode. |
| `content/catalog.js` | Τάξεις (Β΄, Γ΄) και μαθήματα. Εδώ προστίθεται νέο μάθημα ή αλλάζει η κατάστασή του σε `ready`. |
| `content/links.js` | Σελίδα «Χρήσιμα Links». |
| `content/math.js` | Κατηγορίες της σελίδας «Βασικά Μαθηματικά». |
| `content/math/<υποκατηγορία>.js` | Περιεχόμενο κάθε υποκατηγορίας (π.χ. `tautotites.js`, `dekadika-klasmata.js`). Φορτώνεται πριν το `content/math.js`. |
| `content/<τάξη>/<μάθημα>/chapter-0N/` | Θεωρία ανά κεφάλαιο, μία ενότητα ανά αρχείο. Το πεδίο `num` (π.χ. `"2.7"`) καθορίζει το κεφάλαιο της ενότητας. |
| `exercises/<τάξη>/<μάθημα>/chapter-0N/groups.js` | Ομάδες ασκήσεων του κεφαλαίου. Κάθε ομάδα έχει πεδίο `chapter`. |
| `exercises/<τάξη>/<μάθημα>/chapter-0N/*.js` | Οι ασκήσεις, ανά ομάδα. |
| `images/<τάξη>/<μάθημα>/...` | Εικόνες εκφωνήσεων και λύσεων. |
| `simulations/` | Προσομοιώσεις, με ξεχωριστά αρχεία JS και CSS. |
| `LICENSE.md` | Άδεια χρήσης (CC BY-NC-SA 4.0). |

Οι ασκήσεις ενός κεφαλαίου ονομάζονται `chNN-MM-<περιγραφή>.js`, όπου `NN` το κεφάλαιο και `MM` το υποκεφάλαιο (διψήφια).

## Routes

| Route | Περιεχόμενο |
|---|---|
| `#/` | Αρχική: επιλογή τάξης, προσομοιώσεις, χρήσιμα links, βασικά μαθηματικά. |
| `#/grade/b`, `#/grade/c` | Μαθήματα της τάξης. |
| `#/simulations` | Κατάλογος προσομοιώσεων. |
| `#/simulations/fwg` | Αποστακτήρας κενού (Fresh Water Generator). |
| `#/simulations/hydrophore` | Υδροφορικό δοχείο γλυκού νερού. |
| `#/simulations/ejector-evaporator` | Τρισδιάστατο μοντέλο εβαπορέτας με εκχυτήρα. |
| `#/links` | Χρήσιμα links. |
| `#/math` | Βασικά μαθηματικά. |
| `#/math/proapaitoumenes-gnoseis` | Προαπαιτούμενες γνώσεις για τα Μαθηματικά Γ΄ Λυκείου. |
| `#/math/proapaitoumenes-gnoseis/tautotites` | Αλγεβρικές ταυτότητες με αποδείξεις. |
| `#/math/proapaitoumenes-gnoseis/idiotites-dynameon` | Ιδιότητες δυνάμεων και προϋποθέσεις εφαρμογής. |
| `#/math/proapaitoumenes-gnoseis/kanones-paragontopoiisis` | Κανόνες και μέθοδοι παραγοντοποίησης. |
| `#/math/mathimatika-gia-olous` | Βασικά μαθηματικά για όλους. |
| `#/math/mathimatika-gia-olous/dekadika-klasmata` | Δεκαδικά κλάσματα. |
| `#/math/dekadika-klasmata` | Παλιός σύνδεσμος, διατηρείται για συμβατότητα. |
| `#/thermo/...` | Θερμοδυναμική: σημειώσεις και πίνακας ασκήσεων (`content/b/thermod/`, `exercises/b/thermod/`). |
| `#/egkatastaseis-klimatismou/...` | Εγκαταστάσεις Κλιματισμού: θεωρία και ασκήσεις Τράπεζας Θεμάτων. |

Οι διαδραστικές ασκήσεις ταυτοτήτων ορίζονται σε ομάδες στο `content/math/tautotites.js` και ελέγχουν την ισοδυναμία αλγεβρικών παραστάσεων.

## Προσθήκη περιεχομένου

Για ασκήσεις Τράπεζας Θεμάτων η προτεινόμενη διαδικασία είναι το `process-inbox` του agent, που παράγει τα αρχεία και ενημερώνει αυτόματα `index.html` και `catalog.js`. Τα παρακάτω περιγράφουν τη χειροκίνητη διαδικασία.

### Νέο μάθημα

1. Πρόσθεσε το μάθημα στο `content/catalog.js` με `"status": "soon"`. Εμφανίζεται ως «Σύντομα» και δεν είναι διαθέσιμο για κλικ.
2. Δημιούργησε τους φακέλους `content/<τάξη>/<μάθημα>/` και `exercises/<τάξη>/<μάθημα>/`, ακολουθώντας τη δομή του `content/b/thermod/` και του `exercises/b/thermod/`.
3. Όταν το περιεχόμενο είναι έτοιμο, όρισε `"status": "ready"` και `"href"` (π.χ. `"#/antoxi"`). Πρόσθεσε το route-prefix του μαθήματος στη συνάρτηση `route()` του `js/app.js`, με πρότυπο το `"thermo"`.

### Νέο κεφάλαιο σε υπάρχον μάθημα

1. Δημιούργησε `content/<τάξη>/<μάθημα>/chapter-0N/*.js` με ενότητες που έχουν `num` να ξεκινά από `"N."`.
2. Δημιούργησε `exercises/<τάξη>/<μάθημα>/chapter-0N/groups.js` με τις ομάδες του κεφαλαίου (`"chapter": "N"`).
3. Δημιούργησε `exercises/<τάξη>/<μάθημα>/chapter-0N/*.js` με ασκήσεις που παραπέμπουν σε αυτές τις ομάδες.
4. Πρόσθεσε τα αντίστοιχα `<script>` tags στο `index.html`, πριν το `js/app.js`, με τη σειρά: θεωρία, `groups.js`, υπόλοιπες ασκήσεις του κεφαλαίου.

Η αρχική σελίδα του μαθήματος, το sidebar και ο πίνακας ασκήσεων προσαρμόζονται αυτόματα (αριθμός ενοτήτων και ασκήσεων, ομαδοποίηση ανά κεφάλαιο) χωρίς αλλαγές στο `js/app.js`.

## Σελίδα άσκησης και πλοήγηση

**Κεφαλίδα άσκησης.** Παράγεται από τα μεταδεδομένα της άσκησης και εμφανίζει διαδοχικά:

```text
<Μάθημα> – <Υποκεφάλαιο>
<Είδος άσκησης> · <Μονάδες>
Θέμα 2ο · #<κωδικός>
```

**Πλοήγηση.** Στην αριστερή στήλη η ιεραρχία είναι μάθημα, κεφάλαιο, υποκεφάλαιο, άσκηση. Η ενεργή άσκηση, ή η ενεργή ενότητα θεωρίας, κεντράρεται κατακόρυφα μέσα στη στήλη, τόσο με επιλογή από τη λίστα όσο και με «Επόμενη». Η κύλιση περιορίζεται στη στήλη και δεν μετακινεί την υπόλοιπη σελίδα. Η λογική βρίσκεται στη συνάρτηση `centerActiveNav()` του `js/app.js`.

## Εμφάνιση

### Dark mode

Το κουμπί εμφανίζεται σε κάθε σελίδα: στο topbar των γενικών σελίδων, στο topbar του μαθήματος σε κινητό και στο sidebar σε desktop. Η προτίμηση αποθηκεύεται στο `localStorage` με κλειδί `site-theme-v1` και ισχύει σε όλο το site.

### Μεγέθη γραμματοσειράς της κεφαλίδας άσκησης

Ορίζονται κεντρικά ως CSS variables στο `css/style.css`:

| Μεταβλητή | Περιοχή |
|---|---|
| `--fs-exercise-kicker` | Γραμμές μαθήματος/υποκεφαλαίου και είδους/μονάδων. |
| `--fs-exercise-title` | Τίτλος `Θέμα 2ο · #κωδικός`. |

## Άδεια χρήσης

Το περιεχόμενο διατίθεται υπό CC BY-NC-SA 4.0 (βλ. `LICENSE.md`). Μια σύντομη γραμμή με την άδεια εμφανίζεται αυτόματα σε κάθε γενική σελίδα (`#/`, `#/grade/...`, `#/links`, `#/math`) και σε κάθε σελίδα θεωρίας μαθήματος, μέσω της `licenseFooter()` στο `js/app.js`. Δεν χρειάζεται να προστεθεί χειροκίνητα σε νέο μάθημα.

Η αναλυτική παράγραφος πηγών (ΙΕΠ, σχολικό βιβλίο) εμφανίζεται μόνο στην αρχική σελίδα της Θερμοδυναμικής (`#/thermo`), επειδή αφορά τις πηγές του συγκεκριμένου μαθήματος. Κάθε νέο μάθημα χρειάζεται τη δική του παράγραφο με τις δικές του πηγές.

## Εκτέλεση και δημοσίευση

Άνοιξε το `index.html` σε Chrome, Edge ή Firefox. Δεν απαιτείται server ή εγκατάσταση.

Εξωτερικές εξαρτήσεις, που φορτώνονται από CDN:

- Γραμματοσειρές και KaTeX.
- Three.js και OrbitControls, μόνο όταν ανοίξει η τρισδιάστατη προσομοίωση. Χωρίς αυτές, οι υπόλοιπες λειτουργίες της (ρυθμίσεις, μετρήσεις, διάγραμμα) συνεχίζουν να λειτουργούν.

Για δημοσίευση σε GitHub Pages αρκεί να εκτεθούν τα στατικά αρχεία του φακέλου όπως είναι.
