# Θερμοδυναμική — refactored

Το αρχικό `thermodynamiki.html` χωρίστηκε σε ξεχωριστά αρχεία χωρίς αλλαγή στη λογική της εφαρμογής.

## Δομή
- `index.html`: το κέλυφος της εφαρμογής
- `css/style.css`: όλο το υπάρχον CSS
- `content/chapter-01/`: θεωρία του Κεφαλαίου 1, μία ενότητα ανά αρχείο
- `exercises/chapter-01/`: ασκήσεις ανά ομάδα (`units`, `energy`, `systems`, `calc`)
- `js/app.js`: ο υπάρχων μηχανισμός εφαρμογής / rendering / interactions

## Εκτέλεση
Άνοιξε το `index.html` σε Chrome/Edge/Firefox. Για GitHub Pages, το repository μπορεί να δημοσιεύσει απευθείας αυτά τα static HTML/CSS/JS αρχεία.
