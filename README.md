# Μηχανολογία ΕΠΑΛ — σημειώσεις & ασκήσεις

Στατικό site (χωρίς build tools): άνοιξε `index.html` ή δημοσίευσέ το με GitHub Pages.

## Δομή
- `index.html`: το κέλυφος της εφαρμογής (όλα τα `<script>` tags φορτώνουν εδώ)
- `css/style.css`: όλο το CSS (περιλαμβάνει και τα dark-mode χρώματα)
- `content/catalog.js`: οι τάξεις (Β', Γ') και τα μαθήματά τους — εδώ προσθέτεις νέο μάθημα ή το κάνεις "ready" όταν είναι έτοιμο
- `content/links.js`: η σελίδα «Χρήσιμα Links» — εδώ προσθέτεις συνδέσμους για μαθήματα/σχολείο
- `content/math.js`: οι κατηγορίες της σελίδας «Βασικά Μαθηματικά»
- `content/math/<υποκατηγορία>.js`: το περιεχόμενο κάθε υποκατηγορίας (π.χ. `dekadika-klasmata.js`, `tautotites.js`), που φορτώνεται πριν από το `content/math.js`
- Οι διαδραστικές ασκήσεις ταυτοτήτων ορίζονται σε ομάδες μέσα στο `content/math/tautotites.js` και ελέγχουν ισοδυναμία αλγεβρικών παραστάσεων.
- `content/<τάξη>/<μάθημα>/chapter-0N/`: θεωρία ανά κεφάλαιο ενός μαθήματος (π.χ. `content/b/thermod/chapter-01/`), μία ενότητα ανά αρχείο. Το πεδίο `num`, π.χ. `"2.7"`, καθορίζει σε ποιο κεφάλαιο ανήκει η ενότητα
- `exercises/<τάξη>/<μάθημα>/chapter-0N/groups.js`: οι ομάδες ασκήσεων του κεφαλαίου (κάθε ομάδα έχει `chapter` ώστε ο πίνακας να τις χωρίζει ανά κεφάλαιο)
- `exercises/<τάξη>/<μάθημα>/chapter-0N/*.js`: οι ίδιες οι ασκήσεις, ανά ομάδα
- `simulations/`: προσομοιώσεις του site, με ξεχωριστά αρχεία JavaScript και CSS
- `js/app.js`: όλη η λογική (routing, rendering, interactions, dark mode)
- `LICENSE.md`: άδεια χρήσης (CC BY-NC-SA 4.0)

## Πλοήγηση / routes
- `#/` — αρχική: επιλογή τάξης (Β', Γ') + διαδραστικές προσομοιώσεις + Χρήσιμα Links + Βασικά Μαθηματικά
- `#/grade/b`, `#/grade/c` — μαθήματα της τάξης
- `#/simulations` — κατάλογος διαδραστικών προσομοιώσεων
- `#/simulations/fwg` — αποστακτήρας κενού (Fresh Water Generator)
- `#/links` — χρήσιμα links
- `#/math` — βασικά μαθηματικά
- `#/math/proapaitoumenes-gnoseis` — προαπαιτούμενες γνώσεις για τα Μαθηματικά Γ΄ Λυκείου
- `#/math/proapaitoumenes-gnoseis/tautotites` — οι βασικές αλγεβρικές ταυτότητες με αποδείξεις
- `#/math/proapaitoumenes-gnoseis/idiotites-dynameon` — οι ιδιότητες δυνάμεων και οι προϋποθέσεις εφαρμογής τους
- `#/math/proapaitoumenes-gnoseis/kanones-paragontopoiisis` — κανόνες και μέθοδοι παραγοντοποίησης
- `#/math/mathimatika-gia-olous` — βασικά μαθηματικά για όλους, μαζί με τα δεκαδικά κλάσματα
- `#/math/mathimatika-gia-olous/dekadika-klasmata` — δεκαδικά κλάσματα
- `#/math/dekadika-klasmata` — παλιός σύνδεσμος προς την ενότητα δεκαδικών κλασμάτων
- `#/thermo` και παρακάτω — το μάθημα Θερμοδυναμική (σημειώσεις + πίνακας ασκήσεων), περιεχόμενο στο `content/b/thermod/` και `exercises/b/thermod/`

### Προσθήκη νέου μαθήματος
1. Πρόσθεσε το μάθημα στο `content/catalog.js` με `"status": "soon"` (εμφανίζεται σαν "Σύντομα", δεν κλικάρεται).
2. Δημιούργησε τους φακέλους `content/<τάξη>/<μάθημα>/` και `exercises/<τάξη>/<μάθημα>/` (π.χ. `content/b/antoxi/`, `exercises/b/antoxi/`), ακολουθώντας ακριβώς το πρότυπο του `content/b/thermod/` / `exercises/b/thermod/`.
3. Όταν είναι έτοιμο, άλλαξε σε `"status": "ready"` και βάλε `"href"` (π.χ. `"#/antoxi"`), και πρόσθεσε το δικό του route-prefix μέσα στο `route()` του `app.js` (ακολουθώντας το πρότυπο του `"thermo"`).

### Προσθήκη νέου κεφαλαίου σε υπάρχον μάθημα
1. Δημιούργησε `content/<τάξη>/<μάθημα>/chapter-0N/*.js` με sections που έχουν `num` ξεκινώντας από `"N."`.
2. Δημιούργησε `exercises/<τάξη>/<μάθημα>/chapter-0N/groups.js` με τα groups του κεφαλαίου (`"chapter": "N"`).
3. Δημιούργησε `exercises/<τάξη>/<μάθημα>/chapter-0N/*.js` με ασκήσεις που παραπέμπουν σε αυτά τα groups.
4. Πρόσθεσε τα αντίστοιχα `<script>` tags στο `index.html`, με τη σειρά: content → groups.js → υπόλοιπες ασκήσεις κεφαλαίου, πριν το `js/app.js`.

Η αρχική σελίδα του μαθήματος, το sidebar και ο πίνακας ασκήσεων προσαρμόζονται αυτόματα (αριθμός ενοτήτων/ασκήσεων, ομαδοποίηση ανά κεφάλαιο) χωρίς άλλες αλλαγές στο `app.js`.

## Dark mode
Κουμπί dark mode σε **κάθε** σελίδα: στο topbar των γενικών σελίδων (`#/`, `#/grade/...`, `#/links`, `#/math`), στο topbar του μαθήματος σε κινητό, και στο sidebar σε desktop. Η προτίμηση αποθηκεύεται στο localStorage (`site-theme-v1`) και ισχύει σε όλο το site — συμπεριλαμβανομένου του topbar, που πλέον σκουραίνει κι αυτό.

## Πνευματικά δικαιώματα
Μια σύντομη γραμμή με το CC BY-NC-SA 4.0 εμφανίζεται αυτόματα σε κάθε γενική σελίδα (`#/`, `#/grade/...`, `#/links`, `#/math`) και σε κάθε σελίδα θεωρίας κάθε μαθήματος (`content/links.js`-style footer, function `licenseFooter()` στο `app.js`) — δεν χρειάζεται να την ξαναγράφεις χειροκίνητα σε κάθε νέο μάθημα. Η αναλυτική παράγραφος με τις συγκεκριμένες πηγές (ΙΕΠ, σχολικό βιβλίο) παραμένει μόνο στην αρχική σελίδα της Θερμοδυναμικής (`#/thermo`), γιατί αφορά τις πηγές αυτού του συγκεκριμένου μαθήματος· κάθε νέο μάθημα θα χρειαστεί τη δική του αντίστοιχη παράγραφο με τις δικές του πηγές.

## Εκτέλεση
Άνοιξε το `index.html` σε Chrome/Edge/Firefox. Δεν χρειάζεται internet (εκτός από τις γραμματοσειρές). Για GitHub Pages, το repository μπορεί να δημοσιεύσει απευθείας αυτά τα static HTML/CSS/JS αρχεία.
